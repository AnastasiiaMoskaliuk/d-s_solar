# D&S Solar – Unternehmenswebsite

Eine moderne, responsive Website für **D&S Solar**, ein Unternehmen im Bereich Solarenergie und Photovoltaik.

## Über das Projekt

Dieses Projekt ist die Entwicklung einer modernen Unternehmenswebsite für D&S Solar.

Das Ziel der Website ist es, das Unternehmen professionell im Internet zu präsentieren und potenziellen Kunden einen einfachen Zugang zu Informationen über Solarenergie, Photovoltaikanlagen und die angebotenen Dienstleistungen zu ermöglichen.

Der Fokus liegt auf einem modernen, minimalistischen und benutzerfreundlichen Design sowie auf einer übersichtlichen Darstellung der wichtigsten Informationen.

Die Website soll Vertrauen schaffen und die Vorteile von Solarenergie verständlich vermitteln.

## Ziele des Projekts

- Professionelle Präsentation des Unternehmens
- Moderne und benutzerfreundliche Oberfläche
- Responsive Design für Desktop, Tablet und Smartphone
- Klare Darstellung der angebotenen Dienstleistungen
- Verbesserung der Online-Präsenz des Unternehmens
- Einfache Kontaktaufnahme für potenzielle Kunden
- Suchmaschinenoptimierung (SEO)

## Geplante Seiten

- **Startseite** – Übersicht über das Unternehmen und die wichtigsten Leistungen
- **Über uns** – Informationen über D&S Solar
- **Leistungen** – Übersicht der angebotenen Dienstleistungen
- **Projekte** – Präsentation bereits realisierter Projekte
- **FAQ** – Antworten auf häufig gestellte Fragen
- **Kontakt** – Kontaktformular und weitere Kontaktmöglichkeiten

## Hauptfunktionen

- Modernes und minimalistisches Design
- Vollständig responsive Darstellung
- Navigation zwischen mehreren Seiten
- Hero-Bereich mit Call-to-Action
- Vorstellung der Dienstleistungen
- Projektgalerie
- Kundenbewertungen
- FAQ-Bereich
- Kontaktformular

- SEO-optimierte Seitenstruktur

## Dienstleistungen

Auf der Website werden unter anderem folgende Dienstleistungen vorgestellt:

- Planung von Photovoltaikanlagen
- Installation von Solaranlagen
- Photovoltaik für Privathaushalte
- Photovoltaik für Unternehmen
- Individuelle Beratung
- Wartung und Betreuung von Solaranlagen

## Design

Das Design basiert auf einem modernen und minimalistischen Stil.

Die wichtigsten Gestaltungselemente sind:

- Helle und klare Hintergründe
- Dunkle, moderne Typografie
- Gelbe Akzente als Verbindung zur Sonne
- Hochwertige und realistische Fotografien
- Moderne Häuser und Photovoltaikanlagen
- Großzügige Abstände
- Klare und übersichtliche Benutzeroberfläche

Das Logo von D&S Solar besteht aus einem **Solarmodul mit einer Sonne darüber** und symbolisiert erneuerbare Energie und nachhaltige Technologie.

## Verwendete Technologien

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **ESLint**

## Warum Next.js?

Für dieses Projekt wird **Next.js mit React und TypeScript** verwendet.

Next.js eignet sich besonders gut für eine moderne Unternehmenswebsite mit mehreren Seiten. Das Framework bietet gute Möglichkeiten für Performance, SEO, Routing und eine strukturierte Entwicklung.

Durch React können wiederverwendbare Komponenten erstellt werden. Dadurch bleibt der Code übersichtlich, wartbar und leicht erweiterbar.

## Zielgruppe

Die Website richtet sich hauptsächlich an:

- Privatpersonen, die eine Solaranlage installieren möchten
- Hausbesitzer
- Unternehmen
- Kunden, die ihre Energiekosten reduzieren möchten
- Personen, die auf erneuerbare Energien umsteigen möchten
